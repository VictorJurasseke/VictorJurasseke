## 💼 O que já construí

**Sistema de gestão de manutenções industriais**
Sistema corporativo completo desenvolvido para uma empresa do setor industrial. Centralizou o fluxo de solicitações, melhorou o controle de execução e trouxe rastreabilidade total às manutenções.

Funcionalidades: fluxo completo de solicitações · formulários dinâmicos configuráveis · delegação e acompanhamento técnico · dashboards operacionais · métricas de SLA · relatórios em PDF · notificações automáticas por e-mail · controle de equipamentos · histórico e rastreabilidade de ações · controle de acesso por níveis de usuário.

Stack: React · Node.js · SQL Server · JWT
